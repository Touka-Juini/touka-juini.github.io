Embedded Systems · IoT ISAMM · 2024

Smart Medicine Box

An academic engineering project combining a Raspberry Pi, electronic sensors, a mobile application, and Firebase to support medication reminders and family notifications.

Raspberry Pi Python Firebase FCM RFID Weight Sensor Mobile App

System highlights

01

Medication reminders

Medication schedules are configured through the mobile app, with audible reminders from the device.

02

RFID authorization

The RFID sensor checks access authorization as part of the device workflow.

03

Weight monitoring

Weight changes help the system assess whether medication may have been removed.

04

Family notifications

Firebase Cloud Messaging (FCM) delivers push notifications to a designated family member.

My contribution

Developed the mobile application, worked on Firebase integration and data management, contributed to software testing, and prepared parts of the technical documentation.

Embedded Systems · Automation Academic Project

Smart Greenhouse Automation

An Arduino-based greenhouse prototype combining environmental sensors, electronic actuators, and a Python desktop application. The project explores environmental monitoring and automated responses to changing greenhouse conditions.

Arduino UNO C++ Python Tkinter PySerial DHT22 Light Sensor Actuators

System highlights

01

Environmental monitoring

A DHT22 sensor measures temperature and humidity, while a light sensor monitors ambient illumination.

02

Automatic lighting

The Arduino controls LED lighting in response to readings from the ambient light sensor.

03

Water-level sensing

A dedicated water-level sensor provides readings for monitoring the water supply.

04

Desktop dashboard

A Python and Tkinter interface was developed for environmental monitoring and intended fan-control functions.

My contribution

Developed the Python desktop dashboard and worked on integrating sensors and actuators, particularly the water-level sensor and fans, connecting hardware monitoring with the user interface.

Project status

Prototype partially working; some functions require further testing and validation.
