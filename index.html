Embedded Systems · IoT 2024

Smart Medicine Box

An academic prototype developed at ISAMM combining a Raspberry Pi, Python, a mobile application, and Firebase to support medication reminders, access authorization, and family notifications.

Raspberry Pi Python Firebase RFID Weight Sensor Mobile App

How it works

  • • The mobile app configures medication schedules.
  • • The Raspberry Pi communicates directly with Firebase.
  • • RFID checks access authorization, while weight changes help indicate whether medication may have been taken.
  • • A buzzer provides audible reminders, and Firebase Cloud Messaging (FCM) sends push notifications to a responsible family member.

My contribution

Mobile application development, Firebase integration and data management, software testing, and technical documentation.
